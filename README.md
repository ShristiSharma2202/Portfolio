# Shristi Sharma Portfolio

React + Vite portfolio using plain CSS (no Tailwind CSS setup required).

## Run locally

1. Install Node.js LTS if it is not already installed.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run build` to verify the project.
5. Run `npm run dev` and open the local URL Vite prints.

Optional: place your resume PDF at `public/Shristi_Sharma_Resume.pdf` to enable the resume download link. Create the `public` folder if it does not exist.



SHRISTI SHARMA PORTFOLIO UPDATE

1. Replace your project's src/App.jsx with this App.jsx.
2. Replace your project's src/styles.css with this styles.css.
3. Copy public/Shristi-formal-Photograph.jpeg into your project's public folder.
4. Ensure src/main.jsx imports the stylesheet, for example: import "./styles.css";
5. Run npm run dev and refresh the browser.

The image path used by App.jsx is /Shristi-formal-Photograph.jpeg. Keep that filename exactly.
Resume and certificate links still expect the corresponding files in public/.
Social links are placeholders and should be replaced with your real profile URLs before publishing.
